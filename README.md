# $RH community website

A static, mobile-friendly website for the Richard Heart ($RH) community token on PulseChain. Open `index.html` locally or serve this directory with a static web server.

## Publish with GitHub Pages

In repository **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. The site uses relative paths and needs no build step.

## Before sharing widely

- Confirm the contract address in `index.html` against the verified $RH community announcement: `0xC1e176A68670b824776643ea2f763D076f04A53d`.
